# 🎬 StreamInsight

**StreamInsight** is a modern **OTT Analytics Platform** built with **React, TypeScript, Vite, and Tailwind CSS**. The project simulates an enterprise-grade streaming analytics workflow by detecting uploaded OTT datasets (Netflix, Amazon Prime Video, and Disney Hotstar) and launching an interactive **Microsoft Power BI Dashboard** through a premium dark-themed web interface.

## 🧠 How It Works

```text
Upload OTT Dataset
        ↓
Platform Detection (Netflix / Prime / Hotstar)
        ↓
Power BI Workspace Launcher
        ↓
QR Code + Dashboard Link Displayed
        ↓
Open Interactive Power BI Dashboard
```

The uploaded file is used for **client-side platform recognition only**. No dataset is uploaded to a backend server.

---

## 📊 Power BI Integration

After a dataset is detected, StreamInsight displays:

* ✅ **Power BI Workspace Connected** status
* 📱 **QR code for mobile access**
* 🔗 **Direct Power BI report link**
* 🚀 **Interactive dashboard launcher button**

This approach preserves the full Power BI experience, including **filters, slicers, and multi-page OTT analytics navigation**.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/musanisameer668-creator/Stream-Insight.git
cd Stream-Insight/StreamInsight-main
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run locally

```bash
npm run dev
```

Open **http://localhost:5173** in your browser.

---

## 🌐 Deployment

The project is deployed on **Vercel**.

To deploy your own version:

```bash
npm run build
```

Then connect the repository to **Vercel** and set the **Root Directory** to:

```text
StreamInsight-main
```
